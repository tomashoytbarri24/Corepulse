# CorePulse REBUILD 146 — Identidad AMD y discos

Versión basada en REBUILD 145. Incluye:

- Logotipo AMD completo, con el nombre de la marca y su flecha oficial.
- Icono y etiqueta de almacenamiento según los datos disponibles de Windows: HDD mecánico, SSD SATA o SSD NVMe.
- Icono genérico cuando Windows no informa el tipo de unidad.
- Color violeta fijo para almacenamiento; el cian de RAM y los colores de CPU/GPU permanecen intactos.
- Sin dependencias nuevas ni cambios en los motores de telemetría.

Los informes locales se guardan en %LOCALAPPDATA%\CorePulse\reportes. Extrae el contenido y abre Iniciar_CorePulse.bat; el encabezado debe indicar Rebuild 146.
